## Content rules

- Each wrestler references shared move definitions plus a moveset.
- Wrestler content cannot contain simulation code.
- Signature/finisher identity is data, but resolution still uses generic move systems.
- Ratings should make style differences visible without making low-rated wrestlers unplayable.
- Names, visual designs, attire, entrance concepts, logos and move names must be reviewed for originality before public release.
