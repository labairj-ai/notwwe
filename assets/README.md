# Asset provenance

All ring, arena, wrestler and audience geometry is generated in `src/render3d`.
The characters use stylized original colors, generic athletic bodies and simple
gear; there are no third-party wrestler meshes, likenesses, tattoos or logos.
Procedural motion is in `src/presentation`; no external animation clip is used.
The favicon is original SVG geometry. Sound is synthesized with oscillators by
`src/audio/audio.js`, with no samples or copyrighted recordings. The entrance
framework plays an original three-note chord, not commercial entrance music.

Three.js is the only shipped third-party asset/runtime: MIT license copied into
`dist/vendor/three/LICENSE`. System fonts require no downloaded font files.
Originality, motion quality and human audible-output review remain pending; the
working codename is not used as the public-facing game title. "Harbor Circuit"
is a provisional original prototype title, not a trademark-clearance claim.
